# تطبيق مجربات كاظم الغيظ

هذه النسخة تحافظ على **تصميم التطبيق وترتيبه وخط Amiri كما هي**، وتضيف العمل دون إنترنت، والتثبيت على شاشة الهاتف، والمزامنة التلقائية، ودخول المشرف الآمن.

## ما الذي تغير تقنيًا؟

| الميزة | السلوك الجديد |
|---|---|
| التحميل الأول | يجلب التطبيق بيانات الختمات من Firebase عند توفر الإنترنت ويحفظ جميع النصوص والصور في IndexedDB. |
| العمل دون إنترنت | يفتح التطبيق والبحث والمفضلة ومحتوى الختمات من الهاتف بعد نجاح التحميل الأول. |
| تحديث البيانات | يفحص التطبيق بصمة البيانات عند الفتح، وعند عودة الإنترنت، وعند الرجوع إلى التطبيق، وكل خمس دقائق أثناء بقائه مفتوحًا. لا يعيد تنزيل 46 ميغابايت إذا لم تتغير البيانات. |
| تحديث ملفات التطبيق | يجلب عامل الخدمة أحدث ملفات التطبيق عند توفر الإنترنت، ويستخدم النسخة المحفوظة عند الانقطاع. |
| إدارة المحتوى | الدخول للمشرف عبر Firebase Authentication بالبريد `hedrnasr7@gmail.com`، ولا توجد كلمة سر ثابتة داخل الشيفرة. |
| التثبيت | ملف manifest وأيقونات Android وiPhone بأحجام صحيحة، ومنها أيقونة تكيفية Maskable. |

> تحتوي قاعدة البيانات الحالية على نحو **1420 سجلًا** ويقارب حجمها **46 ميغابايت**. يجب إبقاء التطبيق مفتوحًا والإنترنت متصلًا حتى يكتمل التحميل الأول. بعد ذلك يعمل المحتوى المحفوظ دون إنترنت.

## الخطوة الأولى: نشر قواعد الحماية

افتح صفحة قواعد قاعدة البيانات في Firebase:

<https://console.firebase.google.com/project/khatmas-app/database/khatmas-app-default-rtdb/rules>

استبدل القواعد الحالية بمحتوى ملف `database.rules.json`، ثم اضغط **Publish / نشر**. تسمح هذه القواعد بالقراءة للجميع، وتسمح بالإضافة والتعديل والحذف فقط للحساب الموثق `hedrnasr7@gmail.com`.

## الخطوة الثانية: رفع ملفات التطبيق إلى GitHub

ارفع محتويات هذه الحزمة إلى جذر المستودع:

<https://github.com/hedrnasr7-design/khatmas->

يجب الحفاظ على المجلدات `vendor` و`fonts` و`icons` كما هي. ملف عامل الخدمة الصحيح اسمه `sw.js` بلا مسافة. يُحذف الملف القديم الذي كان اسمه `sw. js`.

بعد نشر GitHub Pages، افتح:

<https://hedrnasr7-design.github.io/khatmas-/>

## الدخول الأول للمشرف

اضغط عنوان **مجربات كاظم الغيظ** أعلى التطبيق، ثم أدخل كلمة المرور التي أنشأتها في Firebase. إذا كان البريد غير موثق، سيرسل التطبيق رسالة تحقق إلى `hedrnasr7@gmail.com`. افتح الرسالة واضغط رابط التحقق، ثم أعد الدخول.

عند إغلاق لوحة الإدارة، يسجل التطبيق خروج المشرف تلقائيًا. لا ترسل كلمة المرور لأي شخص ولا تضعها داخل ملفات GitHub.

## كيف تظهر تعديلاتك للمستخدمين؟

أضف أو عدل أو احذف الختمات من لوحة الإدارة الحالية. تُحفظ العملية في Firebase فورًا، ويحدث المستخدمون بياناتهم تلقائيًا عند فتح التطبيق، أو عودة الإنترنت، أو الرجوع إلى التطبيق، أو خلال خمس دقائق إذا ظل مفتوحًا.

أما التغييرات البرمجية المستقبلية، فتنشرها برفع الملفات المعدلة إلى مستودع GitHub نفسه. يجلب التطبيق الإصدار الأحدث عند توفر الإنترنت، مع الاحتفاظ بنسخة تعمل دون اتصال.

## تثبيت التطبيق على الهاتف

| النظام | طريقة التثبيت |
|---|---|
| Android مع Chrome | افتح رابط التطبيق، ثم قائمة المتصفح، واختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**. |
| iPhone مع Safari | افتح رابط التطبيق، واضغط **مشاركة**، ثم **إضافة إلى الشاشة الرئيسية**. |

يظهر التطبيق بعد التثبيت في شاشة الهاتف بأيقونته، ويفتح في نافذة مستقلة مثل التطبيقات الأخرى.

## ملفات النسخة

| الملف أو المجلد | الغرض |
|---|---|
| `index.html` | الواجهة الأصلية نفسها وربط الموارد المحلية. |
| `app.js` | منطق التطبيق والمزامنة ودخول المشرف. |
| `offline-store.js` | تخزين IndexedDB المحلي. |
| `sw.js` | تشغيل التطبيق دون إنترنت وتحديث ملفاته. |
| `manifest.json` | تعريف تثبيت التطبيق. |
| `database.rules.json` | قواعد حماية Firebase. |
| `icons/` | أيقونات الهاتف القياسية والتكيفية. |
| `fonts/` | خط Amiri للعمل دون اتصال. |
| `vendor/` | مكتبات Firebase المحلية اللازمة لفتح التطبيق دون اتصال. |
